## 📋 About

This is the official website for **HAWK FIT HUB**, a premium gym and fitness training center located in Bangalore, India. The site is fully static, mobile-first, and built for performance.

---

## 🌐 Pages

| Page | Description |
|---|---|
| `index.html` | Home — Hero, Services preview, Testimonials, CTA |
| `services.html` | Pricing plans and membership options |
| `about.html` | Our story, team, and stats |
| `contact.html` | Contact form (redirects to WhatsApp) |

---

## 🛠️ Tech Stack

- **HTML5** — Semantic, SEO-optimized markup
- **CSS3** — Custom design system, BEM naming, mobile-first
- **Vanilla JavaScript** — Scroll animations, form validation, nav toggle
- **No frameworks. No dependencies.** — Pure, fast, lightweight.
